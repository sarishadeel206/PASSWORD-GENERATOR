✨ About The Project
Password Generator is a simple and interactive frontend project that allows users to generate random passwords instantly.

The application provides a clean interface with show/hide password, copy to clipboard, and instant password generation functionality.

🚀 Features
🔐 Random Password Generation

👁️ Show / Hide Password

📋 One-Click Copy to Clipboard

⚡ Instant Password Generation

💻 Simple & User-Friendly Interface

📱 Responsive Design

🎨 Clean and Modern UI

✅ Copy Confirmation Message

🛠️ Technologies Used
Technology	Purpose
🟧 HTML5	Application structure
🟦 CSS3	Styling, layout & responsive design
🟨 JavaScript	Password generation & interactivity
📋 Clipboard API	Copy generated password
⭐ Font Awesome	Show / hide password icons
⚙️ How It Works
1️⃣ Generate Password
Click the Generate button to create a random password.

2️⃣ Show / Hide Password
Use the eye icon to switch between visible and hidden password.

3️⃣ Copy Password
Click the Copy button to copy the generated password directly to the clipboard.

4️⃣ Confirmation
After copying, a confirmation message is displayed to the user.
